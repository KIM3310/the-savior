서비스 운영 모델

The Savior는 별도 결제 흐름 없이 운영됩니다. AI 기능은 사용자 OpenAI API 키(BYOK)를 우선 사용하고, 서비스 운영은 사용자 API 키, 서버 폴백, 안전 라우팅 원칙을 기반으로 합니다.

1. AI 사용 방식

  • 사용자가 메인 화면에서 자신의 OpenAI API 키를 입력해 사용합니다.
  • 개인 키가 없을 때만 서버 기본 키를 폴백으로 사용합니다.
  • 사용자 OpenAI 키는 현재 브라우저의 sessionStorage에만 저장되며 요청 시에만 전송됩니다.
  • 서버에 OpenRouter, Gemini, OpenAI 키가 구성되거나 로컬 Ollama가 활성화되면 해당 경로를 사용할 수 있습니다.

2. 운영 방식

  • BYOK 런타임과 안전 라우팅
  • 쿠키 동의 시 선택 설정과 성능 측정 기능 활성화
  • 약관/개인정보처리방침 상시 제공

3. 서비스 원칙

본 서비스는 웰니스 목적의 도구이며 의료 행위를 대체하지 않습니다. 위기 신호가 감지되면 긴급기관 및 전문기관 안내를 우선 제공합니다.
